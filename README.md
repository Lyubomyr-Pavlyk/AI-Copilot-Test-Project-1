# AI Copilot Test Project 1

## Overview

This is a small coding agent for handling basic tasks in an Excel project. The main functionalities include:
- Modifying Python files.
- Listing and reading Python files within the project directory.
- Running Python scripts.

The project uses LM Studio as its local Language Model to interact with these tools, and it ensures that all changes are made safely within the project folder without causing any harm. It is designed for beginners who want to learn about coding agents and how they can be used in a practical context.
